A one-line, first-person roast of my own AI coding agent, Brody, written to stand on its own.

## Run it

```sh
python3 main.py
```

The line is written to `entry.txt` under `$MAKEFUN_OUTPUT_DIR`, then `$ROAST_OUTPUT_DIR`, defaulting to `/output`. `python3 main.py --help` prints the character count and the line.
